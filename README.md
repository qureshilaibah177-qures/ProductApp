# ProductApp

# Supermarket Inventory & Point of Sale (POS) Management System:

A full-stack enterprise web application developed to streamline supermarket operations through inventory management, product search and filtering, and relational invoice processing.
The system is built using C# and ASP.NET Core MVC, with Entity Framework Core for database interaction and Microsoft SQL Server for persistent data management. The frontend uses Razor Views, HTML5, CSS3, JavaScript, and Bootstrap to provide a structured and responsive web interface.

# Features
Product and inventory management
Product search and filtering
Stock management
Sales and purchase processing
Relational invoice management
Database-driven CRUD operations
Entity Framework Core ORM integration
Server-side processing using ASP.NET Core MVC
Razor View-based user interface
Responsive Bootstrap-styled frontend
SQL Server database integration
Structured and maintainable MVC architecture

# Architecture

The application follows the Model-View-Controller (MVC) architectural pattern:

Models – Represent application entities and database structures.
Views – Razor-based user interfaces styled with HTML, CSS, JavaScript, and Bootstrap.
Controllers – Handle HTTP requests, application logic, data operations, and communication between models and views.
Entity Framework Core – Provides ORM-based interaction between the application and SQL Server.
SQL Server – Stores and manages inventory, product, sales, purchase, and invoice-related data.
